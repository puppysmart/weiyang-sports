# 未央体育 · 一站式体育信息平台 H5 V0.4

「未央体育」按策划案 V0.4 搭建并以 H5 形态先行的移动端框架。
2026-11 已并入学生反馈调整版（V0.3→V0.4）：四 Tab 信息架构、月历周报首页、
赛事难度分级、打卡三件套、证书三视角、班团双表审核流、体验营详情与奖励等。
视觉与工程约定沿用天境祁连项目：CSS 变量主题令牌、1rem 圆角卡片、数据与视图分离。

## 已实现的框架能力（V0.4 主线）

| 模块 | 框架内体现 |
|---|---|
| 首页 | 月历（活动日期涂色、今日描圈、点击跳转）+ 近期活动整卡跳转 |
| 全部功能 | 竞技 / 群体 / 服务三组八入口 + 体育部工作台 |
| 赛事中心 | 状态筛选、星级难度 + 推荐水平 + 过往成绩 + 1-5 分难度对照表、报名表单 |
| 系队风采 | 门槛标签（零基础可入/需基础）、队详情、招新报名 |
| 运动体验营 | 名额进度条、详情（时间/地点/内容/剩余名额/参与奖励）、弹窗报名与候补 |
| 约球搭子 | 发布约球（球类 1-5 分水平选择）、应答（localStorage 持久） |
| 打卡活动 | 报名 → 打卡记录（可见范围）→ 排行榜 三件套 |
| 游泳证书 | 公示安排 + 我的查询 + 体委本班统计三视角 |
| 器材与资源 | 器材台账、个人借用、依托活动的批量资源申请 |
| 班团服务 | 预算/决算双表 + 四步审核流可视化 |
| 体育资讯 | 周报（每周五更新）/ 通知公告 / 系队招募 |
| 我的 | 资料编辑、我的系队与报名、活动进度查询 |
| 管理后台 | 待办工单 + 内部工作节点视图 |

## 内容维护

- 所有演示数据在 `js/data.js`：结构与天境祁连 `lib/scenic-data.ts` 同一纪律：改内容不动视图。
- ⚠ 部分数字仍为演示占位，上线前需逐项核对替换；真实工作材料见体育部工作档案。
- 用户产生的演示内容（报名标记、约球帖、打卡）存在浏览器 localStorage，清缓存即重置。

## 从这里到真正的小程序

1. 本框架即交互稿：与同学讨论定稿各页面后，冻结信息架构。
2. 后端按策划案第 4 章选型（FastAPI + PostgreSQL），前端迁移至 uni-app（Vue3），
   本项目的页面结构、数据字段可直接映射为 uni-app 页面与 API Schema。
3. 微信小程序端二期上线（需先确定注册主体，见策划案风险 R1）。
