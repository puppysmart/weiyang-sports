# 未央体育 · 小程序框架预览 V0.2

「未央体育」一站式体育信息平台的移动端框架原型。按策划案 V0.4 的七个模块搭好信息架构，
以移动端网页（H5）形态先行——这正是策划案的技术路线（H5 先行、小程序二期 uni-app 套壳）。
视觉与工程约定沿用天境祁连项目：CSS 变量主题令牌、1rem 圆角卡片、数据与视图分离。

## 立即预览

**在线预览（已部署 GitHub Pages，固定地址）**
<https://puppysmart.github.io/weiyang-sports/> —— 手机任何网络直接打开或扫 `预览二维码.png`。
仓库：<https://github.com/puppysmart/weiyang-sports>（公开仓库，内容更新后自动重新发布）。
注：github.io 在国内个别网络下偶有波动，若打不开优先换个网络（校园网/热点）再试。

**本地开发预览**
双击 `启动预览.bat`（或本目录运行 `python -m http.server 8123`），
浏览器打开 <http://localhost:8123>；F12 切换手机视图调试。

**内容更新方法**
改完 `js/data.js` 等文件后：可直接在 GitHub 仓库网页编辑；或用 git 推送
（当前网络对 github.com:443 直连不稳定时，可用 GitHub Contents API 更新）；
更新后约 1 分钟自动生效。

## 导航架构（V0.2）

底部仅「未央体育 / 个人中心」两个 Tab；八个版块全部为独立子页面（赛事中心、系队风采、
体验营、约球搭子、打卡、证书、班团、器材，另有管理后台）。子页面顶栏带返回按钮与
回首页按钮；跳转基于 `history.pushState`，侧滑返回 / 返回键会先回到首页而不是退出应用。
支持 `#comp` 等哈希直达子页面（深链接）。

## 已实现的框架能力（对齐策划案 V0.4）

| 模块 | 框架内体现 |
|---|---|
| 首页·体育周历 | 预计/已确定双状态周历条目、体育周报 WEEK 栏、八个快速入口 |
| 赛事中心 | 状态筛选（报名中/进行中/已结束/预计）、赛事详情半屏页、报名表单演示（含已报名态） |
| 系队风采 | "入门友好度"标签（零基础可入/需基础）、队详情（训练/成绩/视频集锦占位）、招新报名 |
| 群体活动 | 体验营（名额进度条 + 候补登记）、打卡、约球搭子发帖/应答（localStorage 持久） |
| 班团服务 | 班团工作台时间线（预算/活动记录/决算状态） |
| 物资借用 | 器材台账（可借/总数）+ 借用申请演示 |
| 管理后台 | 待办工单 + 内部工作节点视图（与首页周历联动的双视图设计） |

## 内容维护

- 所有演示数据在 `js/data.js`，结构与天境祁连 `lib/scenic-data.ts` 同一纪律：改内容不动视图。
- ⚠ 目前战绩、名单、数字均为**演示占位**（部分参照未央书院官网"文体活动"栏目与体育部工作资料），
  上线前需逐项核对替换。
- 用户产生的演示内容（报名标记、约球帖）存在浏览器 localStorage，清缓存即重置。
