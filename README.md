# 未央体育 · 小程序框架预览 V0.1

「未央体育」一站式体育信息平台的移动端框架原型。按策划案 V0.4 的七个模块搭好信息架构，
以移动端网页（H5）形态先行——这正是策划案的技术路线（H5 先行、小程序二期 uni-app 套壳）。
视觉与工程约定沿用天境祁连项目：CSS 变量主题令牌、1rem 圆角卡片、数据与视图分离。

## 立即预览

**方式一：公网通道（推荐，手机任何网络都能打开）**
当前由 Windows 计划任务 **WYPreview** 常驻运行（脚本 `C:\temp\wy_preview\wy_tunnel.py`）：
自动维持本地服务器 + 隧道，**断线自动重连**，每次重连自动更新 `预览二维码.png` 与 `预览地址.txt`。
当前公网地址看 `预览地址.txt`。管理：桌面上的服务窗口关闭即停；
重新启动运行 `schtasks /run /tn WYPreview`（或双击 `C:\temp\wy_preview\run.bat`）；
彻底移除：`schtasks /delete /tn WYPreview /f`。
备用：双击本目录 `开启公网预览.bat` 手动开一条（窗口关即失效）。

**方式二：本机浏览器**
双击 `启动预览.bat`（或在本目录运行 `python -m http.server 8123`），
浏览器打开 <http://localhost:8123>。建议用浏览器开发者工具切换到手机视图（F12 → 设备模拟）。

**方式三：同一 WiFi 局域网扫码**
手机与电脑连同一 WiFi，扫 `预览二维码-同一WiFi.png`（指向 http://192.168.3.18:8123）。
前提：① Windows 防火墙放行 8123 端口（已配置规则"未央体育预览8123"）；
② 手机连的是电脑同一个路由器的 WiFi（用蜂窝流量打不开，内网地址外网不可达）；
③ 电脑 IP 变了需重新生成（`ipconfig` 查看，`python -c "import qrcode;qrcode.make('http://<新IP>:8123').save('预览二维码-同一WiFi.png')"`）。

## 已实现的框架能力（对齐策划案 V0.4）

| 模块 | 框架内体现 |
|---|---|
| 首页·体育周历 | 预计/已确定双状态周历条目、体育周报 WEEK 栏、八个快速入口 |
| 赛事中心 | 状态筛选（报名中/进行中/已结束/预计）、赛事详情半屏页、报名表单演示（含已报名态） |
| 系队风采 | "入门友好度"标签（零基础可入/需基础）、队详情（训练/成绩/视频集锦占位）、招新报名 |
| 群体活动 | 体验营（名额进度条 + 候补登记）、打卡、约球搭子发帖/应答（localStorage 持久） |
| 班团服务 | 班团工作台时间线（预算/活动记录/决算状态） |
| 物资借用 | 器材台账（可借/总数）+ 借用申请演示 |
| 管理后台 | 待办工单 + 内部工作节点视图（与首页周历联动的双视图设计） |

## 内容维护

- 所有演示数据在 `js/data.js`，结构与天境祁连 `lib/scenic-data.ts` 同一纪律：改内容不动视图。
- ⚠ 目前战绩、名单、数字均为**演示占位**（部分参照未央书院官网"文体活动"栏目与体育部工作资料），
  上线前需逐项核对替换。
- 用户产生的演示内容（报名标记、约球帖）存在浏览器 localStorage，清缓存即重置。

## 从这里到真正的小程序

1. 本框架即交互稿：与同学讨论定稿各页面后，冻结信息架构。

   本项目的页面结构、数据字段可直接映射为 uni-app 页面与 API Schema。
3. 微信小程序端二期上线（需先确定注册主体，见策划案风险 R1）。
